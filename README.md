# הלב של ליה ❤️

לב תלת־ממדי אינטראקטיבי לילדים. אפשר לסובב אותו, להפוך אותו לשקוף, להיכנס לחדרים, לראות את המסתמים נפתחים ונסגרים, לצפות בפעימה בהילוך איטי עם אק"ג, לרכוב על תא הדם "טיפי", להגדיל עד בועיות הריאה, להקשיב ללבבות של חיות ולגלות כמה פעמים הלב פעם מאז שנולדת.

**האתר:** https://xsprite85-bit.github.io/lia-heart/ · **מדיניות פרטיות:** [privacy.html](https://xsprite85-bit.github.io/lia-heart/privacy.html)

## מה יש בו
- **ילדים:** כמה ילדים באותו טלפון. לכל ילד שם, בן או בת, גיל, דמות ותאריך לידה (לא חובה), וכוכבים משלו. הקריינות פונה בלשון זכר או נקבה ואומרת את השם (39 שמות מוקלטים).
- **רמות גיל:** 3–6 הסברים פשוטים, 7–10 קצת יותר מדע, 11+ המונחים האמיתיים.
- **שפות:** עברית ואנגלית, כולל הקריינות.
- **משחקים:** 33 משימות, חידות, "מה טוב ללב?", לבבות של חיות, דרגות ותעודה להדפסה.
- **ביצועים:** מצב חסכוני שנדלק לבד בטלפונים חלשים, או ידנית בפינת ההורים.

## אפליקציה לילדים — פרטיות ובטיחות
- אין איסוף מידע, אין חשבונות, אין פרסומות, אין כלי מעקב. הכול נשמר רק בטלפון (localStorage).
- כל הקבצים (גופן, three.js, קול) נטענים מהאתר עצמו, בלי בקשות לשרתים אחרים.
- **פינת ההורים** נעולה בשאלת חשבון: ניהול ילדים, שפה, ביצועים, איפוס, מדיניות פרטיות, קרדיטים, והבהרה שזה לא כלי רפואי. הקישורים החוצה נמצאים רק שם.
- לא משתמשים במצלמה, במיקרופון או במיקום.

## התקנה כאפליקציה
פותחים את האתר בכרום בטלפון ← תפריט ⋮ ← "התקנת אפליקציה" או "הוספה למסך הבית".

## מבנה
- `index.html`: האתר. `v/`: קליפי הקול (mp3). `lib/three/`: three.js. `privacy.html`: מדיניות הפרטיות.
- `src/`: קוד המקור.
  - `template.html`: הדף. `kids.js`: פרופילים, שפה, פינת הורים, חיות, "מאז שנולדתי", דרגות, "מה טוב ללב", מצב חסכוני.
  - `i18n_src.py`: כל התרגומים — אנגלית (`EN`), לשון זכר (`M`), הסברים לגילאים גבוהים (`ADV`) ורשימת השמות.
  - `assemble.py`: מרכיב את הדף ומפיק את רשימת המשפטים להקלטה (כל שפה ומין).
  - `build_site.sh`: בונה את האתר ואת הגרסה בקובץ אחד.
  - `build.py`: בונה את המודל ואת מסלולי הדם מ־BodyParts3D.
- `voice/heart_voice.py`: מקליט את הקריינות ב־Gemini TTS (קול Kore). `voice/clips/`: התזמונים של כל קליפ.

## בנייה מחדש
בתיקיית העבודה (עם `node_modules/three` בגרסה 0.170.0 וקליפי ה־mp3 ב־`voice/clips`):
```bash
GK=<gemini key> ./build_site.sh rec   # מקליט רק משפטים חדשים או כאלה שהשתנו, ובונה את האתר
```
את המפתח מעבירים רק כמשתנה סביבה. לא שומרים אותו בקבצים.
